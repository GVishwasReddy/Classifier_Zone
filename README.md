# Semantic Segmentation of Aerial Imagery

This project performs semantic segmentation on aerial imagery to identify different objects and regions.

## Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd <repository-name>
   ```

2. **Create a virtual environment and install dependencies:**
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

## Usage

- The main notebook for this project is located in the `notebooks` directory.
- To run the project, open and run the cells in the `notebooks/semantic-segmentation.ipynb` notebook.
